# Stage2 Runtime Evidence Manifest

本清单是文档级 Derived Report（派生报告），不是 Runtime Authority（运行时权威），不持有 live Runtime 对象。逻辑模块路径与测试目标用于定位证据；不保存绝对路径、测试机信息、业务正文、原始异常、Provider 配置或故障注入规则标识。

`status` 表示 Claim 所涉及 Capability 的实现状态，例如 `SUPPORTED`、`PARTIALLY_SUPPORTED`、`CONTRACT_ONLY`、`NOT_IMPLEMENTED`。Claim 是否已经验证不由 `status` 表达，而由 `evidence_level`、`primary_test_targets` 和 `execution_evidence` 表达；`CONTRACT_ONLY` 不表示 Claim 未验证。

`primary_test_targets` 可填写具体 pytest Node ID 或真实测试文件路径；多个目标用 `<br>` 分隔。`execution_evidence` 只记录本轮已有 Gate、最终验收与真实测试执行能够支持的事实，不能从 Markdown 中的结果字样反推。
