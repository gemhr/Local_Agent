## Semantic Categories

- Retryable provider failure：仅 Model/Tool policy 明确允许且预算、deadline、幂等证据均允许时重试。
- Publication partially persisted：Journal 或 Snapshot evidence 显示 committed/partial 时禁止重做业务或自动重存。
- Outcome unknown / Manual reconciliation required：Tool/worker started 但 completion 不权威时人工对账。
- Capability unsupported / Evidence corrupted：fail closed，不升级写回，不当作空数据。
- Diagnostic degraded：Observability/Trace 失败不等于业务未执行。
- Shutdown deferred：保留 worker/resource 真值，不能强关 Model 或伪造 idle。
