## 第 14 天：Model Routing、Fallback 与 Circuit Breaker

### 学习内容

- 主动 Model Routing（模型路由）
- Fallback（降级）
- Escalation（能力升级）
- Circuit Breaker（熔断器）
- Closed、Open、Half-Open
- Retry、Fallback 和熔断边界
- 本地模型与远程模型健康状态
- 首选模型与备用模型
- 模型切换循环

- 不同模型输出一致性

### LocalAgent 正式实现目标

完成轻重模型切换的主要生产版本：

```text
任务特征
→ ModelSelectionPolicy
→ 首选 Model Profile
→ Runtime 检查 Budget / Deadline / 熔断状态
→ Model Adapter 执行
→ Retry
→ 必要时 Fallback 或 Escalation
```

### 具体能力

- 简单任务优先本地轻量模型。
- 复杂规划、长上下文、多 Agent、高风险任务优先远程高级模型。
- 本地模型能力不足时可升级远程。
- 远程模型不可用时按策略降级本地。
- 用户可强制指定本地或远程。
- 某些任务禁止降级。
- 记录选择原因和切换原因。
- 防止：
  - 本地 → 远程 → 本地循环
  - 重试与 Fallback 叠加失控
  - 已产生部分流式输出后无提示切换模型
- Model Adapter 不负责判断任务复杂度。
